# 记录列表：简介预览与封面放大

## 背景

共享媒体（记录）的简介（`description`）可在添加/编辑弹窗写入并落库，但列表卡片未展示，编辑后用户看不到内容。封面仅在列表以缩略图展示，无法点击放大；添加/编辑弹窗里封面 uploader 埋在表单底部，也不展示当前封面。

## 目标

1. **列表**：有简介时展示前一段预览（≤40 字全显；>40 字则前 40 字 + `…`）
2. **列表点简介 / 卡片其它区域**：进入评论详情页 `/share/media/:id`
3. **看全文**：打开现有编辑弹窗，简介字段即为原文（不做长按全文 Dialog）
4. **列表点封面**：`showImagePreview` 放大查看
5. **添加 / 编辑弹窗**：封面区挪到表头；编辑展示当前封面；有图时可点放大

## 非目标

- 不改媒体详情页本身的简介/封面布局
- 不改后端 API、数据模型
- 不做长按简介弹 Dialog
- 不抽独立卡片组件、不加新依赖

## 布局

### 列表卡片

简介插在「类型」与「状态 tag」之间：

```
[ 封面 64×80 ]  标题（单行截断）
                类型
                简介预览（有 description 才渲染）
                状态 tag + 时间行
                [编辑图标]
```

- 样式：`text-xs text-gray-500`
- 无简介：不渲染该行
- 无封面：占位图标，不可点预览

### 添加 / 编辑 Dialog

字段顺序：

```
┌─ Dialog ─────────────────
│  [ 封面预览 / 占位 ]     ← 表头
│  van-uploader（max-count=1）
│  标题
│  类型
│  简介（全文，可编辑）
│  日期 / 仅自己可见
└──────────────────────────
```

| 状态 | 表头展示 |
|---|---|
| 添加且未选图 | 占位 |
| 添加已选图 | 预览新图 |
| 编辑未换图 | 预览当前 `coverPath` |
| 编辑已选新图 | 预览新图 |

编辑保留文案「不选则保留原图」。

## 交互

### 列表

| 手势 | 行为 |
|---|---|
| 单击封面（有 `coverPath`） | `@click.stop` → `showImagePreview` |
| 单击占位封面 | 不预览；落到卡片进详情 |
| 单击简介预览 / 卡片其余区域 | 进 `/share/media/:id` |
| 单击编辑 / 左滑 | 不变 |
| 长按简介 | 无特殊处理 |

### Dialog 表头

- 有可展示的图时，点击预览 → `showImagePreview`（与列表、详情评论图一致：`closeable`、`teleport: 'body'`）
- 上传逻辑不变：有新文件才提交 `cover`

## 截断规则

- 常量：`PREVIEW_LEN = 40`（JS 字符串长度）
- 空 / 仅空白：列表不展示预览行
- `length ≤ 40`：原样显示
- `length > 40`：`slice(0, 40) + '…'`
- 编辑弹窗字段始终为完整 `description`

## 实现范围

文件：`front/vue3-vant-mobile/src/pages/records/index.vue`

- 列表已返回 `description`、`coverPath`，无需改 API
- 封面 URL 继续用 `mediaCoverUrl()`
- `openEditMedia` 增加保存当前项 `coverPath` 的 ref，供表头在未换图时预览
- 图片预览对齐 `share/media/[id].vue` 的 `showImagePreview` 用法

## 交付

用户可感知的行为变更：按仓库版本规范 bump 前端 `package.json` version、后端 `application.version`，并在根 `CHANGELOG.md` 记一节（具体版本号在实现计划中对照当前版本填写）。

## 验证

1. 列表有简介 → 显示预览（短文全显，长文带 `…`）；点简介进详情
2. 点列表封面 → 图片预览可缩放关闭；点卡片其它区域仍进详情
3. 打开添加/编辑 → 封面在表头；编辑能看到原封面；选新图预览更新；有图可点放大
4. 编辑弹窗简介字段为完整原文；无简介 / 无封面列表行为与改前一致（除封面区位置调整）
