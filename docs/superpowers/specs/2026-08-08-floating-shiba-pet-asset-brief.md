## 1. 资源格式与规范

### 1.1 推荐格式

| 类型 | 格式 | 说明 |
|------|------|------|
| 静态表情/关键关键 | **PNG 透明底** 或 **SVG** | 主用 PNG；矢量再转 PNG 也可 |
| 短循环动作 | **逐帧 PNG 序列**（优先）/ GIF / APNG / Lottie JSON | 摇尾巴、爬行、磕头建议 **6–12 帧 PNG** 或 Lottie |
| 命名 | `snake_case` | 一状态一文件（首版不做雪碧图） |

### 1.2 画布与安全区

- 画布：**512×512**（App 内缩放到约 176×176 / 88×88）
- 角色约占画布 **70%**，脚底留空，避免裁切尾巴/磕头
- 统一站位：身体中心偏下，**面向略偏右 15°**（或正脸，全套必须一致）
- 透明背景；不要阴影底板（App 可另加）

### 1.3 风格锚点（写入每条提示词）

- Q 版柴犬，圆润可爱，气质 **可怜 / 讨好**，不要凶、不要写实血腥
- 配色：橙棕毛 + 奶油色口鼻（urajiro）+ 黑鼻豆眼
- 线条干净，扁平或轻阴影，表情包级，小尺寸可读
- **同一只狗**：耳形、毛色、鼻型全套一致

### 1.4 授权

若用 AI 生成，确认平台允许商用；接入时在 `assets/shiba-pet/ATTRIBUTION`（或交付包 `README.txt`）注明工具与授权。

## 2. 状态机（生成与实现对齐）

```
idle_happy ──(闲置 3–8s)──► idle_wag ──播完──► idle_happy
     │
     ├── 「打」轻点 ×1～2 ──► hit_1 / hit_2（递进委屈）
     ├── 「打」累计达阈值 ──► bruise_1 → bruise_2 → bruise_3（递进淤青）
     ├── 「抚」累计 N 次（随机）──► react_crawl 或 react_bow
     └── 起床 / 睡觉打卡成功 ──► greet_bow（磕头请安）──► idle_happy
```

### 建议阈值（实现可调）

| 行为 | 建议 |
|------|------|
| 打 | 第 1 次 `hit_1`，第 2 次 `hit_2`，第 3 次起进淤青链（先浅后深），**禁止一下最肿** |
| 淤青 | 约 4–6s 逐步消退，或再挨打才加重一档 |
| 闲置摇尾 | 随机间隔 4–10s，播完回 `idle_happy` |
| 抚摸 | 连续抚 3–5 次后，约 50% `react_crawl` / 50% `react_bow` |

## 5. 分镜与状态脚本

### 5.1 `dog_idle_happy` — 默认待机

- **镜头：** 正面稍侧，坐姿或站立看镜头
- **情绪：** 乖巧、讨好、准备互动
- **要点：** 眼睛亮、微笑；尾巴可见且自然
- **负面：** 生气、龇牙、淤青、脏污

**提示词：**

> {通用前缀} 柴犬安静待机，坐姿面向镜头，温柔微笑，耳朵直立，尾巴自然可见，干净可爱，高可读性小图标风格。

---

### 5.2 `dog_idle_wag` — 闲置摇尾讨好（8 帧）

| 帧 | 动作 |
|----|------|
| 1 | 坐姿微笑，尾巴偏左 |
| 2–3 | 尾巴甩向右，身体几乎不动 |
| 4–5 | 尾巴甩向左，耳朵微颤 |
| 6–7 | 再甩右，眼神更期待 |
| 8 | 回中，接循环 |

- **情绪：** 讨好求摸摸，不是疯跑
- **提示词：**

> {通用前缀} 生成 8 帧连贯动画关键帧：柴犬坐着讨好摇尾巴，身体小幅度晃，表情微笑期待，尾巴左右摆动循环友好，每帧透明底，角色位置固定不要位移出画。

若模型只出单图：按「第 N 帧：尾巴在左/右…」分 8 次生成，并要求锁角色、锁机位。

---

### 5.3 `dog_hit_1` — 轻拍（可怜，不生气）

- **情绪：** 轻惊后立刻委屈可怜
- **要点：** 向上弯的软闭眼或水汪汪圆眼；粉颊；最多一滴小泪；小嘴「呜」，不张大喊
- **负面：** 怒眉、龇牙、张大嘴、怒气符

**提示词：**

> {通用前缀} 柴犬被轻轻点了一下，超级可怜但不生气：软软闭眼或水润眼神，脸颊粉红，小小嘴抿着呜咽，可能一滴眼泪，耳朵略软，可爱委屈。

---

### 5.4 `dog_hit_2` — 再拍（更委屈）

- **递进：** 比 hit_1 更耷耳、泪更多，仍可爱

**提示词：**

> {通用前缀} 柴犬又被轻轻点了一下，比上一张更委屈：耳朵更耷，双眼含泪，小声呜咽，身体微微缩，仍然可爱讨好，绝不是生气或凶恶。

---

### 5.5 `dog_bruise_1` — 浅淤青

- **要点：** 一侧淡青紫 + 小创可贴；卡通创可贴感，非写实血肿

**提示词：**

> {通用前缀} 柴犬轻微鼻青：一侧脸颊淡淡卡通青紫，贴一小块创可贴，表情委屈可怜想讨好，干净可爱，不要写实伤痕，不要恶心肿胀。

---

### 5.6 `dog_bruise_2` — 中淤青

**提示词：**

> {通用前缀} 柴犬中度卡通淤青：双眼附近淡青紫更明显，创可贴稍大，眼泪汪汪，耳朵耷拉，但五官仍端正可爱，像表情包不是写实受伤。

---

### 5.7 `dog_bruise_3` — 重淤青（封顶仍克制）

**提示词：**

> {通用前缀} 柴犬明显卡通鼻青脸肿但仍保持萌：双侧淡青紫+创可贴，眼泪，缩着身子可怜巴巴求饶讨好；禁止恐怖、禁止变形毁容、禁止血腥。

---

### 5.8 `dog_react_crawl` — 抚摸后狗爬（8 帧）

| 帧 | 动作 |
|----|------|
| 1 | 站/坐，开心被摸 |
| 2–3 | 前腿趴下，屁股抬起准备爬 |
| 4–6 | 向前小幅度狗爬 1–2 步（画布内位移很小） |
| 7–8 | 停住抬头看人，讨好笑 |

**提示词：**

> {通用前缀} 8 帧：柴犬被摸后开心狗爬讨好，前低后高小爬几步，最后抬头撒娇，可爱轻快，位置大致居中，透明底。

---

### 5.9 `dog_react_bow` — 抚摸后磕头（8 帧）

| 帧 | 动作 |
|----|------|
| 1 | 站立微笑 |
| 2–3 | 前腿弯曲，头往下 |
| 4–5 | 额头接近地面（磕头），屁股微抬 |
| 6–7 | 抬头一点 |
| 8 | 再轻磕或抬头笑（讨好） |

**提示词：**

> {通用前缀} 8 帧：柴犬磕头作揖讨好，前腿撑地低头触地再抬头，动作柔和恭敬可爱，不要滑稽崩坏，透明底角色居中。

---

### 5.10 `dog_greet_bow` — 起床/睡觉打卡请安（10 帧）

- **语境（勿画字）：** 主人点了「起床」或「睡觉」，小狗郑重请安

| 帧 | 动作 |
|----|------|
| 1 | 端坐/站立，注视 |
| 2–3 | 收前腿，准备鞠躬 |
| 4–6 | 深深磕头请安（头低、停顿 1 帧） |
| 7–8 | 抬头，眼神乖巧 |
| 9–10 | 微微摇尾或再轻轻一点头收尾 |

**提示词：**

> {通用前缀} 10 帧仪式感磕头请安：柴犬对主人请安，恭敬低头触地停顿，再抬头微笑摇尾，可爱郑重，适合「起床/睡觉」打卡反馈，透明底居中。

## 6. 质检清单

每张/每帧检查：

1. 是否同一只柴犬（毛色、耳、鼻）
2. 缩到约 88px 后表情是否仍可辨
3. 挨打相关是否是**可怜**而非生气
4. 淤青是否「卡通创可贴级」，而非写实肿烂
5. 动画帧是否锁机位、无乱跳乱缩
6. 透明底是否干净、无白底方块
