# 伴侣页默认「一起看过的」+ 可选「上次一起看」日期

## 背景

伴侣页（`/share`）默认打开「一起做过的事」。列表中的「上次一起看」目前展示的是 `updateTime`（任意编辑、评论、进度都会触发刷新），无法表达真实的一起观看日期，也无法在添加/编辑时手动指定。

## 目标

1. 绑定伴侣后进入 `/share`，默认落在「一起看过的」Tab，并加载媒体列表。
2. 「上次一起看」改为独立可选手动日期字段；更新共同进度时强制刷新为当天。

## 方案

### 数据模型

在 `shared_media` 增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| `last_watched_at` | `DATE NULL` | 上次一起看的日期；可空 |

Flyway：`V10__add_shared_media_last_watched_at.sql`（若仓库已有更高版本号则顺延）。

旧数据保持 `NULL`；有值才展示「上次一起看」。

### 后端行为

| 操作 | `last_watched_at` |
|------|-------------------|
| 创建媒体 | 请求可带；未传则默认当天 |
| 更新媒体 | 可改、可清空（空值 = 清空） |
| 更新共同进度 `scope=shared` | **强制写成当天** |
| 更新个人进度 / 发评论 / 仅改标题封面等 | **不改** |

- API 响应字段：`lastWatchedAt`（日期字符串，如 `2026-07-19`）。
- 现有 `touchActivity` 继续只碰 `updateTime`（列表活跃排序用），与「上次一起看」解耦。
- 列表文案改读 `lastWatchedAt`，不再读 `updateTime`。

### 前端行为

- `activeTab` 默认 `'media'`；有伴侣时挂载即 `loadMedia()`。
- 添加 / 编辑弹窗增加「上次一起看」：`van-calendar` 选日期（与共享记录日期选择一致）。
  - 新建：默认今天，可改、可清空。
  - 编辑：带出已有值，可改、可清空。
- 列表：仅当 `lastWatchedAt` 有值时显示 `上次一起看：yyyy-MM-dd`。
- 详情页更新共同进度后依赖后端刷新；返回列表即可看到新日期。无需额外交互。

### 不在本期

- 调整 Tab 文案或顺序以外的布局重构
- 按 `last_watched_at` 排序或筛选
- 日期+时间精度
- 进度观看事件历史表

## 验收

1. 打开伴侣页默认是「一起看过的」。
2. 新建媒体默认「上次一起看」为今天；改成其他日期后列表显示所选日期。
3. 编辑可改、可清空；清空后列表不显示该行。
4. 更新共同进度后日期变为今天；更新个人进度、发评论、改标题/封面不改变该日期。

| 区域 | 文件（示意） |
