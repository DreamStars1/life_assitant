# 悬浮柴犬彩蛋 — 角色与美术设计规范

> 锁定现有定稿角色（以 `参考素材` 为基准）。
> 后续所有静帧 / 动画帧必须服从本规范。
> 日期：2026-08-08

---

## 1. 角色圣经（Character Bible）

### 1.1 身份

| 项 | 规定 |
|----|------|
| 物种 | 柴犬（Shiba Inu）幼犬感 |
| 气质 | 乖巧、讨好、可怜时可委屈；**永不生气、不凶、不龇牙恐吓** |
| 用途 | App 悬浮桌宠；缩小到约 88×88 仍需认得表情 |

### 1.2 外形锚点（必须保持一致）

- **头身比**：大头短腿 Q 版，头约占身高 40%～45%
- **耳**：尖三角耳、圆耳尖，内耳浅红/浅粉
- **眉斑**：双眼上方两块奶油色圆形「眉毛」斑（本角色关键识别点，勿删）
- **口鼻**：奶油色 urajiro 口吻区；小黑鼻；嘴线简洁
- **胸腹腿**：奶油色围嘴/胸 bib + 四肢内侧/爪垫偏奶油
- **尾**：柴犬卷尾（cinnamon-roll），橙+奶油，位置在臀后上方
- **轮廓**：中等偏粗的深棕/近黑描边，线宽全套统一
- **阴影**：轻微分区阴影即可，禁止厚重写实皮毛噪点

### 1.3 配色（近似值，按定稿图对齐）

| 区域 | 色感 |
|------|------|
| 主毛 | 暖橙棕 / ginger |
| 口鼻胸腹爪 | 奶油白 / 米白 |
| 描边 | 深棕近黑 |
| 眼珠 | 深棕黑，可有小高光 |
| 内耳 / 腮红 | 浅粉 |
| 卡通淤青 | 淡紫青（低饱和），忌青黑写实淤血 |
| 创可贴 | 米黄底 + 浅橙边 |

## 2. 构图与文件规范

| 项 | 规定 |
|----|------|
| 画布 | **2048×2048**（与现有 asset 一致）或同源比例；导出 App 用时可另缩 |
| 背景 | **纯透明**（生成若出白底，后期去底；禁止复杂场景） |
| 角色占比 | 约画幅 65%～75%；四周留白 |
| 朝向 | **四分之三偏右**（与 `dog-idle-happy` 一致），全套锁定 |
| 地面 | 无阴影底板（或极淡椭圆，全套统一选一种） |
| 格式 | PNG；动画为逐帧 PNG |
| 命名 | 推荐 `dog-<state>-<nn>.png`（连字符，与现有 asset 一致） |

## 3. 表情与情绪规范

### 3.1 总原则

1. **可怜 ≠ 生气**：闭眼用「向上弯」软弧（˘˘），禁用「倒八字怒眉」
2. **挨打递进**：委屈加深、耳渐耷、泪渐多；不要突然毁容
3. **淤青克制**：创可贴表情包级，双侧最重也要五官端正可爱
4. **讨好优先**：待机/摇尾/爬/磕头以撒娇、恭敬为主

### 3.2 已定稿静帧（勿再改设定，只可微调对齐）

| 文件 | 情绪要点 |
|------|----------|
| `dog-idle-happy.png` | 睁眼微笑，坐姿，基准角色 |
| `dog-hit-1.png` | 轻拍：软闭眼或含水光、粉颊、小呜咽 |
| `dog-hit-2.png` | 更委屈：耳更耷、泪更多、身微缩 |
| `dog-bruise-1.png` | 单侧淡青 + 小创可贴 |
| `dog-bruise-2.png` | 双侧淡青更明显 |
| `dog-bruise-3.png` | 最重卡通肿，仍萌，禁写实血肿 |

### 3.3 禁止出现

- 怒牙、火焰、怒气符号、通红暴怒眼
- 写实伤口、脓血、畸形肿胀
- 换品种（柯基/柴太等）、换配色体系
- 文字水印、UI 边框、照片写实背景
- 贴纸白边（若定稿无白边则全套无；若有则全套统一——以 `dog-idle-happy` 为准）

## 4. 动画规范

### 4.1 通用

- **锁机位**：角色锚点（胸口中心）每帧位移 ≤ 画幅 3%
- **锁比例**：头身、线宽、配色每帧一致
- **循环**：摇尾可无缝循环；爬/磕头为一次性短动画，首尾可接回 idle 坐姿或站姿
- **帧率目标**：12～15 fps 观感；交付按帧文件，不强制合成 GIF
- **时长**：摇尾 / 爬 / 抚摸磕头约 0.6～1.2s；打卡请安约 1.2～1.5s

### 4.2 各动作要求

#### A. `dog-idle-wag`（8 帧）— 闲置摇尾讨好

- 身体：坐姿，几乎不动或极轻左右晃
- 尾巴：左右摆动是主运动；卷尾形态保持可辨
- 表情：微笑期待，可与 idle-happy 接近
- 循环：第 8 帧接得回第 1 帧

#### B. `dog-react-crawl`（8 帧）— 抚摸后狗爬

- 姿态：前低后高（play bow / 爬行讨好），不是站立不动
- 位移：向前小爬 1～2 步，整体仍居中
- 表情：开心撒娇
- 参考关键帧：`dog-react-crawl-keyf.png`（仅风格/角色参考；动作需做成真正爬行序列）

#### C. `dog-react-bow`（8 帧）— 抚摸后磕头

- 前腿撑地 → 头低近地 → 抬头；可轻磕两下或一下
- 恭敬可爱，勿崩坏滑稽
- 可参考：`dog-greet-bow-keyfra.png` 的低头触地姿态作为中间高点帧

#### D. `dog-greet-bow`（10 帧）— 起床/睡觉打卡请安

- 比 react-bow 更「仪式感」：低头停顿 1 帧再抬头
- 收尾可微摇尾或轻点头
- 关键帧参考：`dog-greet-bow-keyfra.png`

## 5. 交互与状态递进（产品侧，供美术理解节奏）

```
idle_happy ←→ idle_wag（闲置自动）
     │
     ├─ 打 ×1 → hit_1
     ├─ 打 ×2 → hit_2
     ├─ 打 ×3+ → bruise_1 →（再打）bruise_2 → bruise_3
     ├─ 抚多次 → 随机 crawl / bow
     └─ 起床/睡觉打卡成功 → greet_bow → idle_happy
```

淤青应**可消退**；不要「一下永久毁容脸」。
