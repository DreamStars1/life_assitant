# Life Assistant 更新说明（用户向）

面向使用者的版本说明。不写技术实现细节；开发向完整日志见根目录 [`CHANGELOG.md`](../CHANGELOG.md)。

发版有用户可见变化时，**必须**与 `CHANGELOG.md`、版本号一并更新本文件（见 `.cursor/rules/app-version-bump.mdc`）。

---

## v1.9.1（2026-08-12）

- 影音详情里看评论图片时，可以左右滑动浏览本条影音下的全部图片（不限同一条消息里的多图）
- 一次选多张图发出去，仍然会合成一条多图消息

## v1.9.0（2026-08-10）

- 修改积分流水日期时，对方需要确认后才会生效（昵称为 cc 时发起修改仍立即生效）
- 可在积分页一键确认全部待确认的改期申请；看板「积分记录」入口有小红点提醒

## v1.8.3（2026-08-10）

- 记录列表展示简介摘要；点击封面可放大查看
- 添加/编辑记录时，封面放在弹窗顶部，方便预览

## v1.8.2（2026-08-08）

- 从某个类型筛选（如书籍）进入添加时，会默认带上当前类型

## v1.8.1（2026-08-08）

- 弹窗内容过长时可以上下滑动，避免简介太长点不到确认

## v1.8.0（2026-08-08）

- 加减积分时可选择记录日期；已有流水也可改日期（按天）

## v1.7.0（2026-08-08）

- 部分账号可见悬浮小狗彩蛋（可拖动、点击互动）

## v1.6.0（2026-08-07）

- 「在一起」日期可编辑，双方同步；在一起天数按该日期计算
- 积分余额展示更稳定

## v1.5.0（2026-08-03）

- 新增健康管家：今日情况、身体档案、趋势；可从「我的」进入

## v1.2.0（2026-07-10）

- 共享媒体可标记已看完、列表可左滑删除
